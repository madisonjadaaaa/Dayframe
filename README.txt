DAYFRAME v8

Bible scheduling model changed:
- A Bible plan now has a START DATE and a finite LENGTH (1–4 weeks).
- Dates before a new plan's start are not rewritten by that plan.
- "Just Today" creates a one-day Bible override for any selected date.
- Example: normal plan = Romans. Monday can be overridden to Exodus 3. Tuesday automatically returns to Romans.
- Calendar day detail includes "Change Bible Study for This Day."
- A one-day override can be removed.
- New passage/topic plans can start on a future date.
- After the plan length ends, the calendar says Plan Complete instead of repeating the same passage forever.
- The app no longer requires displaying Scripture to make the Bible planner useful; it is designed to send you to your own Bible.
